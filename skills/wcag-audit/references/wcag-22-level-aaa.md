# WCAG 2.2 Level AAA (summary)

This file documents common Level AAA success criteria and examples for auditing.

## Key criteria

- 1.4.6 Contrast (Enhanced) — increased contrast for normal text.
- 1.2.6 Sign Language (Prerecorded) — provide sign language interpretation where appropriate.
- 2.2.3 No Timing — avoid time limits or provide user control.
- 2.4.8 Location — provide clear location information in the interface.
- 3.1.3 Unusual Words — explain uncommon vocabulary.
- 3.1.4 Abbreviations — explain abbreviations and acronyms.
- 3.1.5 Reading Level — content should be understandable for the intended audience.
