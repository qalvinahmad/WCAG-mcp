# WCAG 2.2 Level AA (summary)

This file documents common Level AA success criteria and examples for auditing.

## Key criteria

- 1.4.3 Contrast (Minimum) — text and large text should meet contrast minimums.
- 1.4.4 Resize text — text should be resizable up to 200% without loss of content.
- 1.4.10 Reflow — content should reflow at 320 CSS px without horizontal scrolling.
- 2.4.7 Focus Visible — keyboard focus indicators must be visible.
- 2.5.8 Target Size (Minimum) — interactive targets should be large enough.
- 3.1.2 Language of Parts — language changes should be programmatically identified.
- 3.3.8 Accessible Authentication — avoid cognitively difficult authentication barriers.
- 4.1.3 Status Messages — status updates should be announced without losing focus.
